셔클의 포지셔닝
운수사·지자체가 AV를 직접 운영할 수 있도록 차량·데이터·플랫폼을 통합 제공하는 AV 운영 인프라.
카카오와의 차이
카카오는 기사 네트워크 기반 → AV 전환 시 강점 소멸.
셔클은 지킬 기사 네트워크 없음 → 동등한 출발선.
Key Risk
에이전트가 이동수단을 고를 때 플랫폼 UI가 아닌 API 신뢰도가 경쟁력이 됨.
